## Where the re-fetch changed or added to the planner's rule sheet

1. **Edge runtime (SSE-9, NC 10).** The Vercel Functions API reference says that starting in
   Next.js 16.3 setting `runtime` to `edge` is no longer supported. nextjs.org only says
   deprecated. Both are stated, and the missing release number stays under NC 10.
2. **`X-Accel-Buffering` (route example).** The Streaming guide itself gives the header for
   Nginx-style reverse proxies, so it is cited there instead of the Self-hosting guide.
3. **Safari buffering (NC 5).** The Streaming guide says Safari and WebKit buffer streaming
   responses until 1024 bytes have arrived. Whether that affects `EventSource` isn't stated.
4. **`src` directory (NC 9).** The duration page says to prefix function routes with `/src/` for a
   `src` project, and shows no complete key, so NC 9 says so instead of claiming nothing is shown.
5. **Error frame name (SSE-14).** The planner's sheet used `event: error`. WHATWG puts any event
   field value on the dispatched event, and MDN defines an `error` event that `EventSource` fires
   itself, so a frame named `error` would reach the connection-error listeners. The frame is
   `stream-error`. The rule keeps `(convention)`.
6. **Effect Events (client hook).** react.dev says Effect Events can only be called from Effects
   and must not be passed to other components or Hooks, so the hook calls `handleMessage` from an
   arrow function inside the listener instead of passing it to `addEventListener`.
7. **Connection limit (SSE-26).** MDN words it as 'when not used over HTTP/2', so the rule says
   'Without HTTP/2'.
8. **AI SDK names (SSE-29, NC 8).** The AI Gateway guide (AI SDK 7, last updated 2026-09-23) reads
   `result.stream` and returns `createUIMessageStreamResponse`, and it has no `abortSignal`. The
   cancellation changelog has `abortSignal: req.signal`. The file says names differ by major.
9. **`vercel.json` page.** It was fetched, but only its opening was read, so its claims (SSE-16, NC 9)
   rest on the Functions API reference and the duration page, which state them in full.
